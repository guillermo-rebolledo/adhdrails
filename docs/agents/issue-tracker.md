# Issue tracker: Linear

Issues and product work for this repo live in the Rails project in the Memoji Inc Linear workspace:

https://linear.app/memoji-inc/project/rails-ab8a7def5698/overview

Use the connected Linear integration for issue operations.

## Conventions

- Create issues in the Rails project.
- Read and search issues through Linear, using the issue identifier when available.
- Keep issue status, assignee, priority, labels, and project membership in Linear.
- Add progress, decisions, and implementation notes as issue comments.
- Apply the triage labels defined in `docs/agents/triage-labels.md`.
- Resolve work by updating the issue to the appropriate completed or canceled status.

## When a skill says “publish to the issue tracker”

Create an issue in the Rails Linear project.

## When a skill says “fetch the relevant ticket”

Read the referenced Linear issue, including its description, labels, status, and comments.
